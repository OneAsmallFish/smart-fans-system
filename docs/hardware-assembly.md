## 焊接顺序

### ⚠️ 关键提示

- **先测后焊**：每步完成后用万用表检查短路（12V→GND, 5V→GND, 3.3V→GND 均应无导通）
- **静电防护**：焊接 ESP32-S3 前佩戴防静电腕带
- **BME280**：LGA封装推荐热风枪回流焊，手焊难度极高

---

### Step 1：电源区焊接（最先验证供电）

1. 焊接 **SATA J1** 连接器
2. 焊接 **F1, F2**（PTC保险丝）
3. 焊接 **D1, D2**（肖特基二极管，注意阳极/阴极方向，阴极朝向负载）
4. 焊接 **U1 AMS1117-3.3**（SOT-223，散热焊盘必须焊牢）
5. 焊接所有电源去耦电容（C1-C9）
6. **测试**：接SATA电源，测量焊盘：
   - 5V轨 → 5.0±0.25V ✓
   - 3.3V轨 → 3.3±0.1V ✓
   - 12V轨 → 12V±10% ✓
   - 所有GND间无短路 ✓

### Step 2：保护电路（ESD）

1. 焊接 **D3**（SRV05-4，USB ESD，SOT-363 小封装注意方向）
2. 焊接 **D4-D8**（TVS管，Tach + DS18B20 ESD保护）

### Step 3：ESP32-S3 核心

1. 焊接 **J2 Type-C**（先对齐再点焊4个角固定）
2. 焊接 **R3, R4**（5.1kΩ CC下拉，紧邻Type-C CC引脚）
3. 焊接 **SW1（RST）, SW2（BOOT）, SW3（WiFi配网）**
4. 焊接 **R1, R2**（EN/IO0上拉10kΩ）, **C14**（EN延时100nF）
5. 焊接 **U2 ESP32-S3-WROOM-1**（模块焊盘间距1mm，逐点焊接，避免连锡）
6. 焊接 ESP32 去耦电容 C10-C13
7. **测试**：接USB，电脑识别串口 `/dev/ttyACM0` ✓

### Step 4：风扇驱动电路

1. 焊接 **U3 74AHCT125**（SOIC-14，注意方向标记）
2. 焊接 **C18**（74AHCT125去耦）
3. 焊接 Tach 电路电阻 R13-R24（12个电阻，按扇区焊接）
4. 焊接 **J3-J6**（4Pin风扇座，对齐方向：Pin1=GND朝向标注方向）
5. 焊接风扇12V去耦电容 C19-C22

### Step 5：传感器和 I/O

1. 焊接 **U4 BME280**（推荐热风枪回流：涂锡膏→放置芯片→300°C热风）
2. 焊接 I²C 上拉电阻 **R25, R26**（4.7kΩ）
3. 焊接 **J7, J8**（DS18B20接线端子）
4. 焊接 OneWire 上拉 **R27**（4.7kΩ）
5. 焊接 **LED1 WS2812B-2020**（注意芯片切角方向）
6. 焊接 **C23, C24**（传感器去耦）

### Step 6：电压监控网络

1. 焊接 **R7, R8**（12V分压：100kΩ+20kΩ，必须±1%精度）
2. 焊接 R9-R12（5V/3.3V分压）
3. 焊接 ADC滤波电容 C15-C17

## 上电前检查清单

- [ ] SATA Pin3（PWDIS）**未连接**（NC，确认）
- [ ] 12V, 5V, 3.3V 轨对 GND 无短路（万用表蜂鸣档）
- [ ] AMS1117 散热焊盘焊牢（对3.3V轨稳定性关键）
- [ ] Type-C CC1/CC2 各有5.1kΩ下拉（USB供电识别）
- [ ] ESP32 天线方向朝向板边空旷处
- [ ] BME280 所有焊盘导通（万用表量芯片引脚对焊盘）
- [ ] WS2812B 方向正确（切角对应GND引脚）

## 风扇连接说明

4Pin PWM 风扇标准接法（Intel规范）：

```
Pin1 ─── GND    （黑色线）
Pin2 ─── 12V    （黄色线）
Pin3 ─── TACH   （绿色线，开漏输出）
Pin4 ─── PWM    （蓝色线，5V逻辑输入）
```

⚠️ 不同品牌风扇颜色定义可能不同，**以Pin编号为准**，不以颜色为准。
购买前确认风扇为 4Pin PWM 规格（非3Pin / DC调速）。

---

## DS18B20 探头接线

```
探头 Pin1 ─── GND
探头 Pin2 ─── DATA  →  J7/J8 DQ 端子
探头 Pin3 ─── VCC   →  J7/J8 VCC 端子（3.3V）
```

两个探头（J7, J8）共用同一 OneWire 总线（GPIO16），传感器 ROM 地址自动识别。

---

## SATA 电源接口注意事项

本板使用 SATA 15Pin 供电（从服务器电源的 SATA 输出接入）：

- **Pin 7-9**：5V 输出 → 板载 AMS1117-3.3 转换为 3.3V
- **Pin 13-15**：12V 输出 → 直供风扇（经保险丝）
- **Pin 1-3**：`⚠️ 不连接`（PWDIS/3.3V，本板不使用）

推荐使用 15cm 左右的 SATA 延长线，连接服务器电源模组空余接口。

## 测试程序烧录（验收测试）

组装完成后，烧录固件并通过 USB-CDC 串口验证：

```bash
# 烧录固件
idf.py -p /dev/ttyACM0 flash

# 打开串口
screen /dev/ttyACM0 115200

# 发送验收命令
> status
{"ok":true,"wifi":false,"mqtt":false,"uptime_s":5,"free_heap":285000,"alert_level":0}

> fan 0 speed 50
{"ok":true}
# 此时 Fan1 应能听到转速变化

> help
{"ok":true,"data":{"commands":["help","reboot","status","ota","fan"]}}
```
