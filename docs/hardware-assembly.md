## 焊接顺序

### ⚠️ 关键提示

- **先测后焊**：每步完成后用万用表检查短路（12V→GND, 5V→GND, 3.3V→GND 均应无导通）
- **静电防护**：焊接 ESP32-S3 前佩戴防静电腕带
- **BME280**：LGA封装推荐热风枪回流焊，手焊难度极高

---

### Step 1：电源区焊接（最先验证供电）

1. 焊接 **SATA J1** 连接器
2. 焊接 **F1（≥3A PTC）, F2（1A PTC）**
3. 焊接 **D1（SS34，12V 防反）、D2/D3（B5819W ×2，5V 与 VBUS 支路二极管或）**——注意阳极/阴极方向，阴极朝负载侧
4. 焊接 **U1 AMS1117-3.3**（SOT-223，散热焊盘必须焊牢）
5. 焊接所有电源去耦电容（含 12V 轨旁 10µF——注意 **≥25V 耐压**方向）
6. **测试**：接SATA电源，测量焊盘：
   - 5V轨 → 5.0±0.25V ✓
   - 3.3V轨 → 3.3±0.1V ✓
   - 12V轨 → 12V±10% ✓
   - 所有GND间无短路 ✓

### Step 2：USB 接口与 ESD

1. 焊接 **J2 Type-C**（先对齐再点焊4个角固定）
2. 焊接 **R3, R4**（5.1kΩ CC下拉，紧邻Type-C CC引脚）
3. 焊接 **U5 USBLC6-2SC6**（SOT-23-6，**注意 Pin5 VCC 接的是 +5V 轨**——原理图勿接 3.3V）
4. **测试**：接USB，电脑识别串口 `/dev/ttyACM0` ✓

### Step 3：ESP32-S3 核心

1. 焊接 **SW1（RST）、SW2（BOOT）、SW3（WiFi 配网）**
2. 焊接 **R1, R2**（EN/GPIO0 上拉10kΩ）、**C_EN**（EN 去抖100nF）、**R_CS**（GPIO44 上拉10kΩ）
3. 焊接 **U2 ESP32-S3-WROOM-1**（模块焊盘间距1mm，逐点焊接，避免连锡）
4. 焊接 ESP32 去耦电容（≥8 只 100nF 分布 VDD 引脚周围）
5. **测试**：接USB 重新枚举，`idf.py flash` 可识别芯片（下载模式：按住 SW2 再按 SW1 复位）

### Step 4：风扇驱动电路（8 路）

1. 焊接 **U3 74AHCT125 ×2**（SOIC-14，注意方向标记；两片的 8 个 OE 脚在原理图中均接 GND）
2. 焊接两片的 100nF 去耦电容
3. 焊接 **PWM 下拉电阻 10kΩ ×8**（GPIO5~12 每路一只，接 GND）
4. 焊接 Tach 网络（每路 3 电阻 + 1 电容）：上拉 10kΩ×8（到 +5V）、串联 10kΩ×8、下拉 10kΩ×8、1nF×8
5. 焊接 **J3~J10**（4Pin风扇座 ×8，对齐方向：Pin1=GND 朝丝印标注）
6. 焊接风扇 12V 去耦电容 100nF ×8

### Step 5：传感器和 I/O

1. 焊接 **U4 BME280**（推荐热风枪回流：涂锡膏→放置芯片→300°C热风）
2. 焊接 I²C 上拉电阻 **4.7kΩ ×2**
3. 焊接 **J11, J12**（DS18B20 接线端子）
4. 焊接 OneWire 上拉 **4.7kΩ ×1**
5. 焊接 **LED1 WS2812B-2020**（注意芯片切角方向）+ DIN 串联电阻（33~100Ω）
6. 焊接 **J13**（屏幕排针 8P）

### Step 6：电压监控网络

1. 焊接 12V 分压：**100kΩ + 20kΩ**（±1% 精度，接 GPIO1）
2. 焊接 5V / 3.3V 分压：**47kΩ + 10kΩ ×2**（接 GPIO2 / GPIO4）
3. 焊接 ADC 滤波电容

## 上电前检查清单

- [ ] SATA Pin1-3（PWDIS/3.3V）**未连接**（NC，确认）
- [ ] 12V, 5V, 3.3V 轨对 GND 无短路（万用表蜂鸣档）
- [ ] AMS1117 散热焊盘焊牢（对3.3V轨稳定性关键）
- [ ] Type-C CC1/CC2 各有5.1kΩ下拉（USB供电识别）
- [ ] USBLC6 Pin5 接 +5V（非 3.3V）
- [ ] 74AHCT125 两片 8 个 OE 脚全部接地、8 路 PWM 下拉电阻在位
- [ ] ESP32 天线方向朝向板边空旷处（15×15mm 禁布区内无铜/无件）
- [ ] BME280 所有焊盘导通（万用表量芯片引脚对焊盘）
- [ ] WS2812B 方向正确（切角对应GND引脚）

## 风扇连接说明

4Pin PWM 风扇标准接法（Intel规范）：

```
Pin1 ─── GND    （黑色线）
Pin2 ─── 12V    （黄色线）
Pin3 ─── TACH   （绿色线，开漏输出）
Pin4 ─── PWM    （蓝色线，5V逻辑输入）
```

⚠️ 不同品牌风扇颜色定义可能不同，**以Pin编号为准**，不以颜色为准。
购买前确认风扇为 4Pin PWM 规格（非3Pin / DC调速）。

**扩展板接入（D1）**：12 路风扇扩展板为成品、独立 SATA 供电，接任意一路 4Pin 风扇座
（建议 Fan8/J10）即可作为普通风扇通道使用，主控板无需任何额外接线和配置。

## DS18B20 探头接线

```
探头 Pin1 ─── GND
探头 Pin2 ─── DATA  →  J11/J12 DQ 端子
探头 Pin3 ─── VCC   →  J11/J12 VCC 端子（3.3V）
```

两个探头（J11, J12）共用同一 OneWire 总线（GPIO16），固件按 ROM 地址自动识别并上报。

## SATA 电源接口注意事项

本板使用 SATA 15Pin 供电（从服务器电源的 SATA 输出接入）：

- **Pin 7-9**：5V 输出 → 经 D2 与 USB VBUS（经 D3）二极管或后进 +5V 轨 → AMS1117-3.3
- **Pin 13-15**：12V 输出 → 经 F1（≥3A）+ D1 → 直供 8 路风扇
- **Pin 1-3**：`⚠️ 不连接`（PWDIS/3.3V，本板不使用）

推荐使用 15cm 左右的 SATA 延长线，连接服务器电源模组空余接口。
单独 USB 供电时板卡可工作（调试场景），SATA 供电时 USB 仅作数据（D4 决策）。

## 测试程序烧录（验收测试）

组装完成后，烧录固件并通过 USB-CDC 串口验证：

```bash
# 烧录固件
idf.py -p /dev/ttyACM0 flash

# 打开串口
screen /dev/ttyACM0 115200

# 发送验收命令（与固件 FW-22 命令集一致）
> status
{"ok":true,"wifi":false,"mqtt":false,"uptime_s":5,"free_heap":285000,"alert_level":0}

> fan 0 50
{"ok":true,"fan":0,"duty":50}
# 此时 Fan1 应能听到转速变化

> wifi status
{"ok":true,"connected":false,"mode_hint":"long-press BTN(GPIO47) 3s = AP provisioning, 10s = factory reset"}

> help
{"ok":true,"data":{"commands":["help","reboot","status","ota","fan","wifi","mqtt"]}}
```
