## 采购建议

### 方式1：嘉立创全套采购（推荐）

1. 打开立创商城 https://www.szlcsc.com
2. 登录账号 → 我的订单 → BOM配单
3. 上传本BOM表格（Excel格式）
4. 自动匹配LCSC编号 → 加入购物车
5. 优势：一站式采购，7天到货，SMT贴片服务可选

### 方式2：淘宝+嘉立创混合

**淘宝采购（更便宜但需等待）：**
- ESP32-S3模组：搜索"ESP32-S3-WROOM-1 N16R8"，价格≈15元
- 风扇座/SATA座：搜索关键词，通常更便宜
- 电容电阻：100个起售，适合批量

**嘉立创采购（快速小批量）：**
- IC芯片（74AHCT125, BME280等）
- 贴片元件（0805阻容）
- PCB制板 + SMT贴片一条龙

### 方式3：PCB + SMT 全套代工

嘉立创提供SMT贴片服务：
- 上传Gerber + BOM + 坐标文件
- 系统自动报价（含PCB + 元件 + 贴片费）
- 5片起订，约 200-300元（含贴片）
- 优势：免焊接，直插元件自己焊即可

## 附录：SATA电源接口定义

```
SATA 15Pin 电源接口引脚定义：
Pin 1-3:   3.3V (本设计不使用，有PWDIS兼容性问题)
Pin 4,11:  GND
Pin 5,12:  GND
Pin 6:     GND
Pin 7-9:   5V  (→ AMS1117-3.3 输入)
Pin 10:    GND
Pin 13-15: 12V (→ 风扇供电)

本设计只使用:
- Pin 7-9 (5V)
- Pin 13-15 (12V)
- Pin 4,5,6,10,11,12 (GND)
```
