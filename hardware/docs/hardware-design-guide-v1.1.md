# 硬件设计完整指南 — 嘉立创EDA版

## 📐 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         主控板 (v1.1)                             │
│  ESP32-S3-N16R8 + SATA供电                                       │
│  ├─ 6路独立PWM风扇控制 (25 kHz)                                  │
│  ├─ 6路Tach转速反馈 (PCNT硬件计数)                               │
│  ├─ BME280 环境传感器 + 2× DS18B20 探头                         │
│  ├─ 12V/5V/3.3V 电源监控                                         │
│  ├─ WS2812B RGB LED 状态指示                                     │
│  ├─ USB-C 原生CDC (编程+调试)                                    │
│  └─ 屏幕接口预留 (SPI 4线 + I2C)                                │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                       扩展板 (v1.0)                               │
│  无主控 + SATA供电                                                │
│  ├─ 12路统一PWM风扇 (共用1路PWM信号)                             │
│  ├─ 从主控板接收PWM控制信号 (3Pin航插: 12V/PWM/GND)              │
│  ├─ 简化设计：无Tach反馈，无独立控制                              │
│  └─ 适用场景：机柜整体通风，风扇同步运行                          │
└─────────────────────────────────────────────────────────────────┘
```

## 🎨 原理图绘制指南 (嘉立创EDA)

### 模块1：电源电路 (主控板)

```
[SATA J1 Pin7-9 (5V)] 
        ↓
    [F2: PTC 1A]
        ↓
    [D2: B5819W 肖特基] (防反接)
        ↓
    [C1: 470µF] ─┬─ +5V_IN
                 │
                 ├─→ [U1: AMS1117-3.3]
                 │        ↓
                 │    [C2: 10µF] ─┬─ +3V3 (ESP32供电)
                 │                 │
                 │                 └─ [C3~C10: 100nF] (去耦)
                 │
                 └─→ +5V (74AHCT125 供电)

[SATA J1 Pin13-15 (12V)]
        ↓
    [F1: PTC 2A]
        ↓
    [D1: SS34 肖特基]
        ↓
    [C11: 100µF] ─┬─ +12V (风扇供电)
                  │
                  └─→ [分压网络] → ADC_12V (GPIO21)
```

**关键参数：**
- AMS1117-3.3 散热焊盘必须焊接到GND覆铜（≥2cm²）
- 12V走线宽度 ≥ 2.0mm（单面6A）
- 5V走线宽度 ≥ 1.0mm
- 3.3V走线宽度 ≥ 0.8mm

### 模块2：74AHCT125 电平转换 (6路PWM)

```
[ESP32 GPIO1~6 (3.3V PWM)]
        ↓
    [74AHCT125 #1]
        Pin1 (1OE) → GND (使能)
        Pin2 (1A)  ← GPIO1
        Pin3 (1Y)  → Fan1_PWM (5V)
        Pin4 (2A)  ← GPIO2
        Pin5 (2Y)  → Fan2_PWM (5V)
        Pin6 (3A)  ← GPIO3
        Pin7 (GND) → GND
        Pin8 (3Y)  → Fan3_PWM (5V)
        Pin9 (4A)  ← GPIO4
        Pin10(4Y)  → Fan4_PWM (5V)
        Pin14(VCC) → +5V
        
    [74AHCT125 #2] (新增)
        Pin2 (1A)  ← GPIO5
        Pin3 (1Y)  → Fan5_PWM (5V)
        Pin5 (2A)  ← GPIO6
        Pin6 (2Y)  → Fan6_PWM (5V)
        Pin9 (3A)  ← GPIO13 (扩展板控制)
        Pin10(3Y)  → EXT_PWM_OUT (5V)
        其余引脚悬空或GND

[去耦电容]
    74AHCT125 #1 Pin14 ─ [100nF] ─ GND
    74AHCT125 #2 Pin14 ─ [100nF] ─ GND
```

---

### 模块3：风扇接口 (单路示意，重复6次)

```
[Fan_J3 (4Pin风扇座)]
    Pin1 (GND)  → GND
    Pin2 (12V)  ← +12V ─ [100nF去耦]
    Pin3 (Tach) → [R: 10k上拉至5V] ┬─ [分压: 10k+10k] → GPIO7 (3.3V)
    Pin4 (PWM)  ← Fan1_PWM (5V)      └─ Tach开漏输出

[分压计算]
    Tach输出: 5V (高) / 0V (低)
    经10k+10k分压: 2.5V (高) / 0V (低)
    符合ESP32 输入要求 (VIH_min=2.31V @ 3.3V_IO)
```

**重要：**
- Tach 必须上拉到 5V（不是 3.3V），否则风扇无法输出信号
- PWM 输入为 5V 逻辑（Intel 4Pin 规范要求 VIH_min=3.8V）
- 每路风扇 12V 引脚并联 100nF 陶瓷电容（去耦）

### 模块4：传感器接口

```
[BME280 (U4) - I2C地址0x76]
    Pin1 (SDI/SDA) ← I2C_SDA (GPIO17) ─ [4.7k上拉至3.3V]
    Pin2 (SCK/SCL) ← I2C_SCL (GPIO18) ─ [4.7k上拉至3.3V]
    Pin3 (SDO)     → GND (地址选择: 0x76)
    Pin5 (CSB)     → 3.3V (I2C模式)
    Pin6 (VDD)     ← 3.3V
    Pin7 (VDDIO)   ← 3.3V
    Pin8 (GND)     → GND
    [去耦: Pin6 ─ 100nF ─ GND]

[DS18B20探头 J9/J10 (XH2.54 3P)]
    Pin1 (GND)  → GND
    Pin2 (DQ)   ← DS18B20_DQ (GPIO16) ─ [4.7k上拉至3.3V]
    Pin3 (VCC)  ← 3.3V

[WS2812B LED1 (2020封装)]
    Pin1 (VDD)  ← 3.3V ─ [100nF去耦]
    Pin2 (DOUT) → NC
    Pin3 (GND)  → GND
    Pin4 (DIN)  ← WS2812B_DI (GPIO48)
    
    注意：3.3V供电时 VIH_min=2.31V < ESP32 VOH=3.0V ✅
```

---

### 模块5：USB-C接口

```
[USB-C J2 (16Pin贴片)]
    A1/A12 (GND)       → GND
    A4/A9  (VBUS)      → +5V_USB ─ [10µF ║ 100nF]
    A5     (CC1)       ← [R: 5.1k] → GND (下拉)
    B5     (CC2)       ← [R: 5.1k] → GND (下拉)
    A6     (D+)        ─┬─ [U5: USBLC6 Pin6] ─→ USB_D+ (GPIO20)
    A7     (D-)        ─┼─ [U5: USBLC6 Pin3] ─→ USB_D- (GPIO19)
    B6/B7  (D+/D-)     ─┘  (并联A6/A7)
    
[ESD保护 USBLC6-2SC6 (SOT-23-6)]
    Pin1 (I/O_1) ← D- from J2
    Pin2 (GND)   → GND
    Pin3 (I/O_2) ← D+ from J2
    Pin4 (I/O_2) → D+ to ESP32
    Pin5 (VCC)   ← 3.3V
    Pin6 (I/O_1) → D- to ESP32
```

### 模块6：屏幕接口预留 (J12 排针8P)

```
[2.54mm 排针 8P]
    Pin1 → 3.3V         (屏幕供电)
    Pin2 → GND
    Pin3 → SPI_SCK      (GPIO41)
    Pin4 → SPI_MOSI     (GPIO40)
    Pin5 → SPI_CS       (GPIO39)
    Pin6 → SPI_DC       (GPIO42)  (数据/命令选择)
    Pin7 → I2C_SDA      (GPIO17)  (共用BME280)
    Pin8 → I2C_SCL      (GPIO18)  (共用BME280)

[支持的屏幕类型]
    - SPI TFT: ST7789/ILI9341 (240×320 / 320×480)
    - I2C OLED: SSD1306 (128×64)
    - 无线方案: ESP32-C3/S2 作为屏幕从机 (预留I2C)
```

### 模块7：扩展板控制输出 (航插J11)

```
[PH2.0 3Pin航插座 - 主控板输出]
    Pin1 → +12V         (from SATA, 扩展板供电)
    Pin2 → EXT_PWM_OUT  (GPIO13 → 74AHCT125 → 5V PWM)
    Pin3 → GND

[连接线长度]
    建议 ≤ 1米 (PWM信号完整性)
    可选屏蔽线 (减少干扰)
```

## 🔧 扩展板原理图 (12路统一控制)

### 简化设计（无MCU）

```
[SATA J1 供电]
    12V → [F1: PTC 5A] → [D1: SS34] → [C1: 1000µF] → +12V_FAN
    5V  → [U1: AMS1117-5.0] → +5V (74AHCT125供电，可选)

[航插J2 (PH2.0 3P母座) - 接收主控PWM]
    Pin1 ← +12V (备用，可不接)
    Pin2 ← PWM_IN (5V逻辑from 主控板)
    Pin3 ← GND

[PWM信号处理]
    PWM_IN ─ [R: 10k上拉至5V] ─┬─→ [扇出到12个风扇Pin4]
                                │
                                └─ [C: 100nF滤波]

[12个风扇接口 J3~J14]
    每个接口:
        Pin1 → GND
        Pin2 ← +12V_FAN ─ [100nF去耦]
        Pin3 → NC (无Tach反馈)
        Pin4 ← PWM_IN (共用)

[PCB布局]
    - 12V走线宽度 ≥ 3.0mm (12个风扇共12A峰值)
    - 星型供电拓扑 (从中心点分叉)
    - 每路风扇并联100nF去耦电容
```

### 走线宽度规则

| 网络类 | 电流 | 走线宽度 | 备注 |
|--------|------|---------|------|
| **12V** | 6A (峰值) | ≥2.0mm | 风扇电源总线 |
| **5V** | 1A | ≥1.0mm | LDO输入 |
| **3.3V** | 0.5A | ≥0.8mm | ESP32供电 |
| **PWM信号** | <10mA | 0.25mm | 74AHCT125输出 |
| **Tach信号** | <1mA | 0.25mm | 风扇反馈 |
| **USB D±** | - | 0.25mm | 差分等长±5mm |
| **I2C** | <5mA | 0.25mm | SDA/SCL |

### 元件布局要点

```
[主控板布局 - 顶层俯视]

    ┌─────────────────────────────────────────┐
    │ [J1 SATA]                   [J2 USB-C]  │
    │                                          │
    │  [U1 LDO] ← (散热区)                     │
    │                                          │
    │      [U2 ESP32-S3]  →天线  (15mm禁布区)→│
    │                                          │
    │  [U3 74AHCT125#1]  [U3 74AHCT125#2]     │
    │                                          │
    │  [J3][J4][J5]  ← 风扇接口行1             │
    │  [J6][J7][J8]  ← 风扇接口行2             │
    │                                          │
    │  [J9][J10]  [J11]  [J12]                │
    │  DS18B20    扩展   屏幕                  │
    │                                          │
    │  [SW1][SW2][SW3]  [LED1]                │
    │  RST  BOOT  WIFI   RGB                  │
    └─────────────────────────────────────────┘
```

**关键约束：**
1. **ESP32天线区域**：模组右侧15mm×15mm禁布区（无铜皮/元件/丝印）
2. **AMS1117散热**：底层GND覆铜≥2cm²，多打过孔（间距2mm）
3. **USB差分线**：D+/D- 等长误差≤5mm，间距0.25mm，远离时钟源
4. **12V/GND**：粗走线 + 底层大面积GND覆铜（回流路径）
5. **去耦电容**：紧贴IC电源引脚（<5mm）

## 🛠️ 嘉立创EDA操作步骤

### 1. 创建项目

1. 打开立创EDA → **新建工程** → 选择"专业版"
2. 工程名称：`Smart-Fan-Controller-Main-v1.1`
3. 创建原理图：右键工程 → 新建 → 原理图文件

### 2. 导入元件库

#### 方法A：从嘉立创商城

1. 原理图界面 → 左侧"库" → "系统库" → 搜索LCSC编号
2. 例如搜索 `C6186` → 找到AMS1117-3.3 → 放置到原理图

#### 方法B：手动创建符号（ESP32-S3）

由于ESP32-S3-WROOM-1不在立创库，需手动创建：

1. 顶部菜单 → **库管理** → **新建元件库**
2. 创建符号：
   - 名称：`ESP32-S3-WROOM-1-N16R8`
   - 封装：矩形 25.5mm × 18mm
   - 引脚：41个（按上面GPIO分配表）
3. 关联封装：
   - 创建PCB封装 → 尺寸25.5×18mm
   - 添加41个SMD焊盘（1.2mm × 0.5mm）
   - 间距1.27mm

### 3. 绘制原理图

按模块顺序绘制（参考上面7个模块）：

1. **放置元件** → 从库中拖拽
2. **连线** → 使用"导线"工具（快捷键 `W`）
3. **网络标签** → 重要信号用网络标签（如 `+12V`, `I2C_SDA`）
4. **电源符号** → 使用"电源端口"（GND/VCC/+3V3等）
5. **元件编号** → 完成后自动编号（工具 → 自动编号）

### 4. ERC检查

1. 顶部菜单 → **检查 → 电气规则检查 (ERC)**
2. 修复所有错误（未连接引脚、电源冲突等）

### 5. 生成网络表并同步到PCB

1. 顶部菜单 → **设计 → 更新PCB**
2. 自动创建PCB文件并导入元件

### 6. PCB布局

1. **板框绘制**：
   - 切换到"机械层" → 绘制100×70mm矩形
   - 圆角半径3mm（可选）

2. **元件摆放**：
   - 参考上面的布局示意图
   - SATA连接器靠左边缘
   - ESP32居中
   - 风扇接口底部排列

3. **自动布线**：
   - 设置规则：12V=2.0mm, 5V=1.0mm, 信号=0.25mm
   - 顶部菜单 → **自动布线**
   - 手动调整关键信号（USB差分线）

4. **覆铜**：
   - 底层全铜GND
   - 顶层12V区域铺铜（避开信号线）

5. **DRC检查**：
   - 工具 → **设计规则检查 (DRC)**
   - 修复间距/线宽违规

### 7. 生成Gerber并下单

1. 顶部菜单 → **制造输出 → Gerber**
2. 点击"一键下单" → 自动跳转嘉立创商城
3. 选择参数：
   - 数量：5片（起订量）
   - 板厚：1.6mm
   - 铜厚：1oz
   - 阻焊：绿色
   - 表面处理：HASL无铅喷锡
4. 加入购物车 → 下单

## 📐 补充设计文档

### 文档1：电气参数计算

**12V分压网络（ADC_12V → GPIO21）**

```
目标：12V → ADC输入≤2.0V (ESP32-S3 ADC1_CH0 安全上限2.45V)

分压比 = R2 / (R1 + R2)
      = 20k / (100k + 20k)
      = 1/6
      = 0.1667

ADC输入电压 = 12V × 0.1667 = 2.0V ✅

实际测量12V范围：10.8V ~ 13.2V
ADC输入范围：1.8V ~ 2.2V (安全)

软件校准公式：
V_12V = ADC_raw × (3.3V / 4095) × 6.0
```

**Tach频率计算**

```
风扇转速：500 ~ 3000 RPM
Tach脉冲：2个脉冲/转 (Intel规范)
频率范围：16.7Hz ~ 100Hz

PCNT计数周期：1秒
RPM = (PCNT_count / 2) × 60
```

**PWM频率选择**

```
LEDC 25 kHz (Intel 4Pin规范)
占空比：0% ~ 100%
分辨率：10bit (1024级)

避免使用频率：
- 避开 50Hz/60Hz 工频谐波
- 避开 WiFi 2.4GHz (24MHz 分频)
```

### 文档2：焊接顺序建议

1. **贴片IC** (U1, U2, U3, U4, U5)
   - 使用热风枪 + 助焊剂
   - ESP32-S3需焊台显微镜（引脚密集）

2. **0805阻容** (R1~RN, C1~CN)
   - 烙铁温度330°C
   - 先焊一端 → 对齐 → 焊另一端

3. **LED1 (WS2812B-2020)**
   - 注意极性（缺角对应GND）
   - 焊盘预上锡 → 热风200°C回流

4. **THT元件** (SATA, USB-C, 风扇座, 按键)
   - 最后焊接
   - 固定孔先点焊 → 引脚焊接

5. **验收测试**
   - 上电前：万用表检查短路（12V-GND, 5V-GND, 3.3V-GND）
   - 上电后：测量电压（3.3V ±0.1V）
   - 烧录测试固件 → USB识别 → LED闪烁
