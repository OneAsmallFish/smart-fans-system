# 原理图审查清单 (Schematic Review Checklist)

## 使用说明

在提交PCB布局前，按此清单逐项检查原理图，避免返工。

**检查流程：**
1. 打印原理图PDF（或双屏对照）
2. 逐项勾选 `[ ]` → `[x]`
3. 发现问题记录在"备注"列
4. 全部通过后方可进入PCB设计

## 常见错误速查

### ❌ 致命错误（必须修复）

1. **电源短路** — VCC直接连GND
2. **极性反接** — 二极管/电解电容/LED方向错误
3. **ADC超压** — 分压后电压>2.45V
4. **USB D+/D-接反** — GPIO19/20错位
5. **I2C无上拉** — SDA/SCL浮空
6. **EN引脚无上拉** — ESP32无法启动

### ⚠️ 警告（影响性能）

1. **去耦电容不足** — 稳定性差
2. **Tach上拉到3.3V** — 风扇无信号输出
3. **PWM输出3.3V直连风扇** — 电平不足
4. **12V走线过细** — 压降大/发热
5. **USB差分线不等长** — 信号质量差
