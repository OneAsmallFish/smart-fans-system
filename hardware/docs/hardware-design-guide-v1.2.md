## 📐 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         主控板 (v1.2)                             │
│  ESP32-S3-N16R8 + SATA供电                                       │
│  ├─ 8路独立PWM风扇控制 (25 kHz, LEDC 8通道全用)                   │
│  ├─ 8路Tach转速反馈 (PCNT 4单元×2通道全用)                        │
│  ├─ BME280 环境传感器 + 2× DS18B20 探头                          │
│  ├─ 12V/5V/3.3V 电源监控 (ADC1: GPIO1/2/4)                       │
│  ├─ WS2812B RGB LED 状态指示 (GPIO45, RMT)                       │
│  ├─ USB-C 原生USB (编程+console+数据, GPIO19/20)                 │
│  └─ 屏幕接口预留 J13 (SPI 4线 + I2C, UART0 让渡)                 │
└─────────────────────────────────────────────────────────────────┘
              │
              ├─ Fan1~7 (J3~J9):  独立 4Pin 风扇
              └─ Fan8 (J10):      接 12 路扩展板（成品，独立 SATA 供电）

总风扇数: 7 独立 + 12 统一 = 19
扩展板（D1 决策）: 用户自购成品板，独立 SATA 供电，接任意一路 4Pin 座即原生可用
（建议 Fan8/J10）；主控板不做任何扩展板专用电路或固件逻辑。
```

## ⚡ 电源架构 v1.2

```
SATA 12V (Pin13-15) → F1 [PTC, hold ≥3A] → D1 [SS34] → +12V 轨
    +12V 轨 → J3~J10 Pin2（8 路风扇，每路 100nF 去耦）
    +12V 轨 → 100k/20k 分压 → GPIO1

SATA 5V (Pin7-9) → F2 [PTC 1A] → D2 [B5819W] ──┐
USB-C VBUS       → D3 [B5819W] ────────────────┴→ +5V 轨
    +5V 轨 → AMS1117-3.3 → +3V3（10µF+100nF 输出，≥8×100nF ESP32 去耦）
    +5V 轨 → 74AHCT125 #1/#2 VCC（各 100nF 去耦）
    +5V 轨 → 8 路 Tach 上拉（10kΩ×8）
    +5V 轨 → USBLC6 VCC（H-08）
    +3V3 → ESP32 / BME280 / WS2812B / DS18B20 / 全部上拉与分压下臂
```

要点：
- F1 hold ≥3A：8 风扇 ≈2.4~2.8A 稳态 + 启动浪涌；2.5A hold 会误跳（原 MF-MSMF250 作废）。
- 12V 载流按 IPC-2150：1oz 外层 2mm 走线仅约 4A（10℃ 温升）——**旧文档"2.0mm=6A"表述错误已废除**。
  4 层板中 12V 在 L3 铺铜（≥5mm 宽或区块铺铜），过孔阵列换层（H-10）。
- SATA Pin1-3（3.3V/PWDIS）不连接。
- USB VBUS 支路可加可选 1A PTC（F3，NC 亦可）。

## 🔧 关键电路规范（原理图绘制按此执行）

### Tach 输入网络（每路 3 电阻 + 1 电容，共 8 组）

```
风扇 Pin3(Tach, 开漏) ──[10kΩ 上拉至 +5V]──┬──[10kΩ 串联]──┬──→ GPIO
                                            │                │
                                          (节点)          [10kΩ 下拉至 GND] + [1nF 至 GND]
高电平 = 5V × 10k/(10k+10k) = 2.5V > VIH 2.31V ✓
```
共需 10kΩ×24 + 1nF×8。**Tach 必须上拉到 5V**（开漏输出，拉 3.3V 无信号）。

### 74AHCT125（2 片，SOIC-14）

- #1：GPIO5~8 → FAN1~4_PWM；#2：GPIO9~12 → FAN5~8_PWM。8 通道全用，无悬空通道。
- 两片 OE1~OE4（Pin1/4/10/13）**全部接 GND**，原理图明确画出。
- VCC=+5V，各配 100nF 去耦。
- **每路 A 输入线（GPIO5~12 PWM 网络）加 10kΩ 下拉到 GND，共 8 只（H-17）**：上电窗口期
  ESP32 引脚高阻、OE 恒使能，无下拉则缓冲输出不定、风扇可能满转数百毫秒。

### USB-C（J2）+ ESD

- CC1/CC2 各 5.1kΩ 下拉；A6/A7 与 B6/B7 并联。
- **USBLC6-2SC6 的 VCC（Pin5）接 +5V 轨**（H-08 修正：按 5V 供电设计，接 3.3V 钳位行为不正确）。
- D± 差分 90Ω、等长误差 ≤5mm、紧邻 J2 放置。
- VBUS 经 D3（B5819W）进 +5V 轨，与 SATA 5V 支路 D2 构成二极管或，杜绝倒灌（H-05）。

### BME280 / DS18B20 / WS2812B

- BME280：I2C 0x76，SDO→GND、CSB→3.3V，SDA/SCL 4.7kΩ 上拉，100nF 去耦。
- DS18B20：GPIO16 OneWire，4.7kΩ 上拉，J11/J12 两探头共用总线。**不支持寄生供电模式**（固件
  bit-bang 驱动按外部供电设计）。
- WS2812B：GPIO45（RMT），DIN 串 33~100Ω（H-14），3.3V 供电（VIH_min=2.31V < VOH 3.0V ✓），
  100nF 去耦，DOUT 悬空。

### ADC 分压网络

| 网络 | GPIO | 上臂 | 下臂 | 分压比 | 满量程电压 |
|------|:----:|------|------|:------:|-----------|
| ADC_12V | GPIO1 (ADC1_CH0) | 100kΩ | 20kΩ | ÷6 | 12V→2.0V |
| ADC_5V | GPIO2 (ADC1_CH1) | 47kΩ | 10kΩ | ÷5.7 | 5V→0.88V |
| ADC_3V3 | GPIO4 (ADC1_CH3) | 47kΩ | 10kΩ | ÷5.7 | 3.3V→0.58V |

全部 ≤2.0V，低于 ADC 安全区上限。旧审查清单"47k+18k"矛盾表述已删除。

### 屏幕接口 J13（2.54 排针 8P）

Pin1=3.3V，Pin2=GND，Pin3=SPI_SCK(GPIO42)，Pin4=SPI_MOSI(GPIO43)，Pin5=SPI_CS(GPIO44，带 10k 上拉)，
Pin6=SPI_DC(GPIO48)，Pin7=I2C_SDA(GPIO17)，Pin8=I2C_SCL(GPIO18)。

关键约束：
1. **ESP32 天线区**：模组天线端 15×15mm 禁布区（keepout 功能实现，非丝印文字），天线端出板边或悬空。

3. **去耦电容**：距 IC 电源脚 <5mm。
4. **USB 差分**：D+/D- 等长 ≤5mm，远离时钟源。
5. **12V**：L3 铺铜，过孔阵列换层到风扇座。

## 🛠️ 嘉立创 EDA 操作流程（v1.2 工程）

1. **新建工程**：嘉立创 EDA 专业版 → 工程名 `Smart-Fan-Controller-Main-v1.2`，**工程文件存仓库 `hardware/lceda/`**（D6：唯一硬件真源）。
2. **放置元件**：系统库按 LCSC 编号搜索（ESP32-S3-WROOM-1 在嘉立创库有现成符号+封装）。
3. **绘制原理图**：按电源 → ESP32 最小系统 → 8 路 PWM → 8 路 Tach → 传感器 → USB → J13 顺序；网络标签用 `+12V/+5V/+3V3/GND` 电源符号。
4. **ERC 清零**：电气规则检查 0 错误 0 警告；对照 `schematic-review-checklist.md`（v1.2）逐项勾选。
5. **更新 PCB** → 板框 99×99 → 按上述布局要点摆放 → 设定走线规则 → 布线 → L2/L3 覆铜 → DRC 清零。
6. **归档**：可编辑工程 + 原理图 PDF + BOM + Gerber + 钻孔 + ERC/DRC 截图证据 → `hardware/`（BOM 按 H-06 生成 `bom-main-board-v1.2.md` + 重写 `hardware/BOM.csv`）。
7. **下单**：一键下单 → 5 片、1.6mm、1oz、HASL 无铅。

## 📐 电气参数计算（速查）

**12V 分压（GPIO1）**：12V × 20k/(100k+20k) = 2.0V ✓；实测 10.8~13.2V → ADC 1.8~2.2V 安全。
软件换算：`V = ADC_raw × (3.3/4095) × 6.0`（5V/3.3V 同理 ×5.7）。

**Tach**：2 脉冲/转，PCNT 1s 窗口，`RPM = count × 60 / 2`；500~3000 RPM → 16.7~100Hz。

**PWM**：LEDC 25kHz（Intel 4Pin 规范），10bit 分辨率。
