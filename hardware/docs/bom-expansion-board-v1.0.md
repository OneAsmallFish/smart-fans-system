# BOM - 扩展板 v1.0 (12路统一控制)

## 设计说明

扩展板为**无主控简化设计**，通过航插从主控板接收PWM信号，控制12个风扇同步运行。

**适用场景：**
- 机柜整体通风（所有风扇同速）
- 简单的散热增强（无需独立控制）
- 成本敏感场景（无MCU，无传感器）

**限制：**
- ❌ 无独立转速反馈（Tach）
- ❌ 无单路控制
- ❌ 无温度传感器
- ✅ 仅接收主控板PWM信号

## 原理图说明

### 供电部分

```
[SATA J1]
    Pin7-9 (5V)   → [可选，本设计不使用]
    Pin13-15(12V) → [F1: PTC 5A] → [D1: SS34] → [C13: 1000µF] → +12V_FAN
    GND           → GND
```

### PWM信号处理

```
[航插 J2 (PH2.0-3P)]
    Pin1 ← +12V (备用，可不接)
    Pin2 ← PWM_IN (5V逻辑 from 主控板GPIO13)
    Pin3 ← GND

[信号处理]
    PWM_IN ─ [R1: 10k上拉至5V] ─┬─ [C14: 10µF滤波]
                                 │
                                 └─→ [扇出到12个风扇J3~J14的Pin4]
```

### 风扇接口（12路相同）

```
[每个风扇座 J3~J14]
    Pin1 (GND)  → GND (星型回流)
    Pin2 (12V)  ← +12V_FAN ─ [C1~C12: 100nF去耦]
    Pin3 (Tach) → NC (悬空，无反馈)
    Pin4 (PWM)  ← PWM_IN (共用)
```

## PCB设计要点

### 板框尺寸

- **尺寸：** 120mm × 80mm
- **厚度：** 1.6mm FR4
- **铜厚：** 1oz (35µm)
- **层数：** 2层（顶层信号 + 底层GND）

### 走线规则

| 网络 | 线宽 | 备注 |
|------|------|------|
| **+12V_FAN** | ≥3.0mm | 12个风扇峰值12A |
| **GND** | ≥3.0mm | 大电流回流 |
| **PWM_IN** | 0.3mm | 5V逻辑信号 |

### 布局建议

```
[扩展板布局 - 120×80mm]

    ┌────────────────────────────────────────────┐
    │ [J1 SATA]                        [J2 航插]  │
    │                                             │
    │  [D1] [F1] [U1] [C13]   (电源区)            │
    │                                             │
    │  [J3] [J4] [J5] [J6]   ← 风扇第1行          │
    │                                             │
    │  [J7] [J8] [J9] [J10]  ← 风扇第2行          │
    │                                             │
    │  [J11][J12][J13][J14]  ← 风扇第3行          │
    │                                             │
    │  [H1]                            [H2]       │
    │                                             │
    │  [H3]                            [H4]       │
    └────────────────────────────────────────────┘
```

### 覆铜策略

1. **底层：** 全铜GND（≥95%覆盖率）
2. **顶层：** 12V电源区域铺铜（星型拓扑）
3. **过孔：** 12V/GND走线每10mm打一个过孔（加强散热）

## 测试步骤

### 上电前检查

1. **万用表检查短路**
   - 12V-GND：开路（>10kΩ）
   - PWM-GND：>5kΩ（上拉电阻）

2. **目视检查**
   - SATA座方向（缺口对准）
   - D1极性（白色线指向+12V）
   - 航插座方向

### 上电测试

1. **仅SATA供电（不接风扇）**
   - 测量+12V_FAN电压：11.8V ~ 12.2V

2. **连接航插线到主控板**
   - 主控板GPIO13输出PWM
   - 测量PWM_IN引脚波形（示波器）
   - 频率：25 kHz，占空比可变

3. **连接1个风扇测试**
   - 风扇应转动
   - 调整主控板占空比：0% → 停转，100% → 全速

4. **连接12个风扇**
   - 所有风扇同步运行
   - 测量12V_FAN电压：≥11.5V（满载）

## 常见问题

### Q1：扩展板能否独立工作？

**答：** 不能。扩展板无MCU，必须从主控板接收PWM信号。

### Q2：能否只连接部分风扇（如6个）？

**答：** 可以。J3~J14任意接，未接的座子悬空即可。

### Q3：12V电源是否需要从主控板引出？

**答：** 不需要。扩展板有独立SATA供电（J1）。航插Pin1的12V为可选备用。

### Q4：能否在扩展板上增加Tach反馈？

**答：** 不推荐。12路Tach需要12个ESP32 GPIO，主控板引脚不足。如需反馈，建议改用两块6路主控板。

### Q5：走线能承受12个风扇电流吗？

**答：** 可以。单风扇峰值0.5A × 12 = 6A，3.0mm走线可承受8A（1oz铜厚，温升10°C）。

## 升级建议

### 可选功能扩展

1. **增加LED指示**
   - 12V电源指示灯（绿色LED + 1kΩ限流电阻）
   - PWM信号指示灯（黄色LED + 逻辑电路）

2. **增加保险丝分组**
   - 将12路风扇分为3组，每组4个
   - 每组独立保险丝（PTC 2A × 3）
   - 提高可靠性，单路故障不影响全局

3. **增加手动调速**
   - 10kΩ电位器 + LM358运放
   - 调节PWM占空比（不依赖主控板）
